main.py
    main() - вызов функции screenshot() из файла screenshot.py, отправка скриншота и промта на локальную ллм в lmstudio с помощью ask_model() функции 
    Основной код, бесконечный цикл вызов функции main() и передача данных в функцию database()  из файла sqlbd.py для записи в бд раз в 5 минут
chekbd.py
    просмотр бд
screenshot.py
     функция screenshot() - делает скриншот экрана с помощью pyautogui, и сохраняет его в папку скриншотов с датой(надо будет убрать сохранение скриншотов)
analyst.py
    аналитика с помощью двух запросов к локальной ллм через lmstudio, использование для двух запросов функции ask_model(), первый запрос: просьба пользователя + промт для составления sql запроса с помощью ллм, получение данных из бд с помощью сгенерированого sql запроса функцией bdrun() из файла sqlbd.py, второй запрос к ллм, уже с данными из бд и просьбой пользователя + промт ответа. 
sqlbd.py
    database() - функция записи активности пользователя в бд
    bdrun() -  функция открытия бд только для чтения, проверкой начала запроса и выдачей результата команды sql переданной при вызове функции  
ask_llm_lmstudio.py
    ask_model() - универсальная функция запроса к llm lmstudio с помощью request, выдает json формат ответа модели
