# Multimodal AI Pipeline

Локальный пайплайн сбора и анализа активности пользователя на Windows: снятие скриншота экрана → передача в локальную vision-модель в [LM Studio](https://lmstudio.ai) → определение действия пользователя → запись в SQLite.

Всё работает **полностью локально**: изображения не покидают компьютер, обращения к внешним API нет.

## Возможности

- 📸 **Скриншот в памяти** — кадр снимается через `pyautogui` и кодируется в base64 в оперативной памяти, файлы на диск не сохраняются.
- 🪟 **Контекст активного окна** — заголовок активного окна Windows определяется заново на каждом цикле и передаётся в модель как подсказка.
- 🧠 **Локальный vision-анализ** — мультимодальная модель в LM Studio определяет, чем занимается пользователь, и возвращает строгий JSON.
- 🗄️ **Журнал в SQLite** — каждая запись: время, приложение, описание активности.
- 📊 **Аналитика на естественном языке** — задаёшь вопрос про свою активность, LLM сама пишет SQL, проверяет и чинит его, затем формулирует ответ.
- 🪟 **Автозапуск** — задача в Планировщике Windows поднимает пайплайн через 5 минут после входа в систему.

## Установка

```bash
git clone git@github.com:lomlom700ekt-beep/multimodal-AI-pipeline.git
cd multimodal-AI-pipeline

python -m venv .venv
.venv\Scripts\activate

pip install -r requirements.txt
```

Запусти LM Studio, загрузи указанные модели и включи локальный сервер (по умолчанию `http://127.0.0.1:1234`).

Создай базу данных (один раз):

```bash
python -c "import sqlite3; c=sqlite3.connect('activity.db'); c.execute('CREATE TABLE IF NOT EXISTS activiti (time text, application text, activity text)'); c.commit()"
```

## Запуск

**Сбор активности** — пишет в базу каждые 5 минут:

```bash
python main.py
```

**Аналитика журнала** — интерактивный диалог с базой:

```bash
python analyst.py
```

Примеры вопросов:
- *«Чем я занимался сегодня утром?»*
- *«Сколько времени я провёл в браузере?»*
- *«Какие приложения я использовал на этой неделе?»*

**Просмотр сырых записей:**

```bash
python chekbd.py
```

## Автозапуск в Windows

Файл `start_main.bat` — лаунчер: при необходимости поднимает LM Studio (проверка порта `1234`), запускает `main.py` из venv и **перезапускает его при падении**. Весь вывод пишется в `startup.log`.

Регистрация задачи в Планировщике Windows (триггер «при входе в систему» с задержкой 5 минут):

```powershell
$action = New-ScheduledTaskAction -Execute "C:\Windows\System32\cmd.exe" `
  -Argument "/c `"<путь-к-проекту>\start_main.bat`"" `
  -WorkingDirectory "<путь-к-проекту>"

$trigger = New-ScheduledTaskTrigger -AtLogOn -User $env:USERNAME
$trigger.Delay = "PT5M"

$principal = New-ScheduledTaskPrincipal -UserId $env:USERNAME -LogonType Interactive -RunLevel Limited

Register-ScheduledTask -TaskName "MultimodalPipeline" -Action $action -Trigger $trigger `
  -Principal $principal -Description "Autostart multimodal AI pipeline activity logger"
```

Запуск без ожидания задержки:

```powershell
Start-ScheduledTask -TaskName "MultimodalPipeline"
```

## Схема данных

```sql
CREATE TABLE activiti (
    time        text,   -- метка времени YYYY-MM-DD_HH-MM-SS
    application text,   -- заголовок активного окна приложения
    activity    text    -- краткое описание действия пользователя
);
```

## Как это работает

```
main.py
  │
  ├─ screenshot()  ─────────►  кадр экрана → base64 (в памяти, без файлов)
  ├─ get_active_window_title() ► заголовок активного окна Windows
  │
  ├─► ask_model()  ─────────►  LM Studio (127.0.0.1:1234) + скриншот + промт
  │                              └─► строгий JSON: {"activity": "..."}
  │
  └─► database()   ─────────►  INSERT INTO activiti (...) VALUES (...)
                                    │
                                    └── каждые 5 минут

analyst.py
  │
  ├─► ask_model()    ───────►  LLM пишет SQL по вопросу пользователя
  ├─► chek_code_sql() ──────►  прогон SQL; при ошибке LLM чинит запрос (до 5 попыток)
  ├─► bdrun()        ───────►  выборка данных (только SELECT / WITH)
  └─► ask_model()    ───────►  LLM формулирует человеческий ответ по данным
```
